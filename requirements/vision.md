# Vision Document: Figma i18n DLC

## Executive Summary

Figma UX 시나리오에서 텍스트를 자동 추출하고, UX 흐름의 문맥을 이해하여 도메인에 맞는 다국어 번역을 수행한 뒤, i18n 적용된 FE 컴포넌트 코드까지 자동 생성하는 도구입니다. 개발자가 수동으로 수행하던 key 추출 → 번역 → 코드 적용 작업을 AI(EXAONE 2.0)와 Figma MCP를 활용하여 자동화합니다.

## Problem Statement

현재 FE 개발자는 Figma에 작성된 영어 UX 시나리오를 보고:
1. 텍스트를 하나씩 확인하여 i18n key를 수동으로 네이밍
2. 각 key에 대해 다국어 번역을 수행하거나 요청
3. 번역된 값을 locale JSON 파일에 입력
4. 해당 key를 FE 코드에 적용

이 과정에서 **문맥 오역**이 빈번하게 발생합니다. 예를 들어 Signage 도메인에서 "Player"는 "게임 플레이어"가 아닌 "재생 장치"로 번역되어야 하지만, 문맥 없이 번역하면 오역이 발생합니다. 또한 수백 개의 텍스트를 수동 처리하는 데 상당한 시간이 소요됩니다.

## Target Users

| 사용자 | 니즈 |
|--------|------|

| 번역 담당자 | 문맥 정보와 함께 번역하여 오역 감소 |
| UX 디자이너 | Figma에서 작업한 시나리오가 코드에 정확히 반영되는지 확인 |
| PM/PO | 다국어 적용 일정 단축, 품질 향상 |

## Full Scope Vision

### Feature Area 1: Figma 텍스트 추출
- Figma MCP를 통한 페이지/프레임/텍스트 노드 자동 추출
- UX 시나리오 흐름(페이지 순서) 자동 파악
- 텍스트 역할 분류 (제목, 버튼, 설명, placeholder 등)

### Feature Area 2: 문맥 인식 번역
- UX 흐름 기반 도메인/문맥 자동 추론
- 도메인 용어집 자동 참조 및 적용
- 동일 단어의 문맥별 다른 번역 지원
- EXAONE 2.0 모델을 활용한 한국어 최적화 번역

### Feature Area 3: i18n 코드 생성
- 계층적 i18n key 자동 네이밍
- 다국어 locale JSON 파일 자동 생성 (en, ko, ja, zh-CN)
- React 컴포넌트 코드 자동 생성 (react-i18next 적용)

### Feature Area 4: 품질 보증
- 번역 품질 자동 검증 (용어집 준수, key 일관성, 포맷 보존)
- 리뷰 리포트 자동 생성
- 피드백 루프 (검증 실패 → 재번역)

### Feature Area 5: 운영/변경 관리
- Figma 변경 감지 → 기존 번역 diff 비교
- 용어집 진화 관리
- CI/CD 파이프라인 연동

### 핵심 차별점 요약

#### 1. Shift Left — 디자인 단계에서 i18n 시작
기존 도구는 개발자가 코드를 작성한 **이후**에 번역을 적용합니다. 우리는 **디자인 단계**에서 바로 시작하여 개발 전에 번역이 완료됩니다.

```
[기존 방식] 디자인 → 개발 → i18n key 수동 추출 → 번역 요청 → 적용 → QA
[우리 방식] 디자인 → 자동 추출+번역+코드 생성 → 개발에 바로 적용
```

#### 2. UX 시나리오 단위 문맥 번역
기존 도구는 "텍스트 단위"로 번역합니다 (스크린샷을 보여주는 정도). 우리는 **UX 흐름(화면 순서, 프레임 계층)을 분석**하여 같은 단어도 문맥에 따라 다르게 번역합니다.

예시:
- Signage 도메인 Player 관리 화면 → "Player" = "재생 장치"
- Gaming 도메인 사용자 프로필 화면 → "Player" = "플레이어"

#### 3. End-to-End 원스톱 (디자인 → JSON → 코드)
경쟁사는 "Figma ↔ 번역 플랫폼" 연동까지만 합니다. 우리는 **FE 컴포넌트 코드까지 자동 생성**하여 개발자가 즉시 사용 가능합니다.

#### 4. 자가발전 (Self-improving)
번역 메모리(Vectra)와 용어집이 사용할수록 축적되어 품질이 지속적으로 향상됩니다. 기존 SaaS 도구의 TM과 달리, 벡터 유사도 검색으로 "비슷한 문맥"의 이전 번역을 참조합니다.

#### 5. LG EXAONE 한국어 특화
범용 번역 엔진(Google, DeepL) 대비 한국어 이해도가 높은 EXAONE 2.0을 활용하여, 한→일/중 번역 시 한국어 뉘앙스를 더 정확하게 반영합니다.

### 경쟁사 한계 상세

| 경쟁사 | 주요 한계 |
|--------|----------|
| **Crowdin** | Figma 플러그인은 텍스트 push/pull만 지원. Key는 수동 매핑 필요. 문맥은 스크린샷 첨부 수준. 코드 생성 없음 |
| **Lokalise** | Figma 연동은 유사하나 $144~$999/월 고가. 문맥 분석은 수동. 한국어 특화 없음 |
| **Phrase Strings** | Figma 미리보기로 시각 컨텍스트 제공하지만, UX 흐름 분석은 불가. 코드 생성 없음 |
| **i18next-scanner** | 이미 작성된 코드에서 key를 추출만 함. 번역/생성 기능 없음. 디자인 연동 불가 |
| **ChatGPT/범용 LLM** | 일회성 번역. 용어 일관성 보장 안 됨. 히스토리/메모리 없음. 시스템 통합 불가 |
